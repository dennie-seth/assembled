# CHR-1 requires every character-generation output to record both its own
# frame_delta_range and its Arm-C benchmark comparison (arm_c_benchmark +

# smaller category -- single static-pose keyframes that are not an assembled
# sheet at all, so there is no second frame to measure a delta against -- is
# called out separately below (T-0339); it does not shrink toward zero the
# same way because the fields are structurally inapplicable, not merely
# unmeasured.
