## Context

`AudioAgent` shares a base class with `AssetAgent` (T-0071) - DRY per
`docs/PLAN.md` Phase 7 - driving ACE-Step/Stable Audio the same way
AssetAgent drives ComfyUI.

**Revised per `docs/HANDOFF.md` Section 3 (D-20).** Also carry **bus
assignment metadata** per generated asset - Ambience, Music, World SFX,
or Gameplay SFX. D-20 makes the bus a gameplay property (gameplay SFX are
never ducked, so telegraph audibility depends on correct routing), not a
mix setting decided later - so it has to be recorded at generation time,
not bolted on afterward. Consumed by T-0103's client-side bus routing.

## Acceptance

- [ ] `AudioAgent` generates music/SFX end-to-end via the shared base
      class interface
- [ ] Same license-allowlist guardrail as `AssetAgent` applies here too
- [ ] Every generated audio asset carries a bus-assignment field (one of
      Ambience / Music / World SFX / Gameplay SFX) alongside its other
      metadata
