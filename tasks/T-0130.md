## Context

`01` Section 5 defines identity completion as holding `N_exit` uniques
simultaneously. The Round 1/2 sim has no notion of this exit condition, so
completion rate could not be measured -- this blocked INV-14 analysis
(T-0133), which needs a well-defined completion event to measure
time-to-completion against. Depends on T-0129 because completion is
identity-level state that must survive collapse/universe transitions.

## Story

As a simulation author, I want an identity to complete when it holds
`N_exit` uniques simultaneously, with completion events recorded and
timestamped, so that completion rate is reportable per population point
and later cards (T-0133) can measure time-to-completion.

## Acceptance

- [ ] An identity is marked complete the moment it simultaneously holds
      `N_exit` uniques (`01` Section 5)
- [ ] Completion events are recorded with a timestamp (simulation tick or
      wall-clock equivalent)
- [ ] Completion rate is reportable per population sweep point (e.g.
      fraction of identities completed by end of run, at each `P`)
