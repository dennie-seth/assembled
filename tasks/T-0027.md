## Context

Each task card's `agent:` field (infra|server|client|assets|audio|null)
maps to a specific `.claude/agents/*.md` definition, each of which already
declares its own `tools:` allowlist. This task wires that allowlist into
the `--allowedTools` flag `ClaudeCliRunner` passes, so a runner invocation
can never exceed what the assigned agent is scoped to.

**Bootstrap note:** implemented directly this session.

## Acceptance

- [ ] Runner invocation for a card resolves `--allowedTools` from the
      card's `agent:` field via the matching `.claude/agents/*.md`
- [ ] Test: a tool call outside the resolved allowlist is denied
- [ ] `agent: null` cards have no elevated tool access beyond a safe
      read-only default
