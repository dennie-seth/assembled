## Context

New task from `docs/HANDOFF.md` Section 4. D-20: gameplay SFX are never
ducked. Music ducks ambience only. Entity telegraph is the sole warning
for no-LOS entities, so masking it with ducking is a fairness bug, not a
mix choice - this requires a four-bus split: Ambience (duckable), Music,
World SFX (lightly duckable), Gameplay SFX (priority, never ducked).

Depends on T-0082, which makes bus assignment a per-asset metadata field
carried by `AudioAgent` - this task is the client-side routing that reads
that metadata and wires each asset to the correct Godot bus.

## Acceptance

- [ ] Four Godot audio buses exist: Ambience, Music, World SFX, Gameplay
      SFX
- [ ] Music ducking attenuates Ambience only
- [ ] World SFX is lightly duckable; Gameplay SFX is never ducked under
      any condition
- [ ] Test: triggering music ducking never attenuates the Gameplay SFX bus
- [ ] Each asset's bus assignment comes from the metadata added in
      T-0082, not a hardcoded per-call choice
