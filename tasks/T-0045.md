## Context

HTTP handler for note composition per `docs/design/03-net-protocol.md`
Section 2: `{archetype_id, anchor_tag, template_id, slots[], facing?,
item_ref?}`. No free-text field exists anywhere in this request shape -
that's the whole point of the UGC guarantee.

## Acceptance

- [ ] Unknown `template_id` -> `400`
- [ ] Slot arity/category mismatch -> `400`
- [ ] Composing above the caller's unlocked vocabulary tier -> `403`
      (03-net-protocol.md Section 2)
- [ ] Valid request -> `201 {id}`
