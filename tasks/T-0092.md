## Context

New task from `docs/HANDOFF.md` Section 4. Every variant must implement
every anchor tag its archetype declares (`docs/design/04-data-model.md`
Section 2). A missing tag is a **build failure**, never something that
ships silently - this is INV-12 (`docs/design/08-invariants.md` Section 1).

Per the handoff's suggested order, this wants to exist **before variants
themselves are authored** - build the gate first, then content can't drift
from it.

## Acceptance

- [ ] Build-time (or CI-time) check compares each archetype's declared
      anchor tags against every one of its variants
- [ ] Test: a variant missing a required tag fails the build
- [ ] Test: a variant implementing an extra, undeclared tag produces a
      warning, not a failure
