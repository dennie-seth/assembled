## Context

HANDOFF §20-b1. Stream B (character art) — longest lead, start first. Answers
whether a 40px figure survives the descent as a readable silhouette before any
further character art is generated.

`docs/design/13-asset-pipeline.md` §3.5 (Characters — the hard class): at
384×216 a figure is 40px tall. Nearly all generated detail is destroyed in
the descent; what survives is shape and a few value blocks. One sheet per
animation state; ControlNet pose grid guides layout. Square grid keeps SDXL
on its native aspect bucket.

| | |
|---|---|
| Figure height | 40px |
| Cell | 48×48 (3 tiles) |
| Grid | 3×3 — 8 frames + 1 spare |
| Native sheet | 144×144 |
| Generation | 1152×1152 (×8); fallback 1008 (×7) if 8 GB strains |

## Story

Character generation spike, player idle sheet only. Determines whether the
pipeline can produce a readable 40px silhouette before committing to the full
character art budget (~82 frames across player + three entities).
