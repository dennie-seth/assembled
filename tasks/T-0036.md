## Context

A fast local subset of CI (lint + unit tests, not full builds/exports) run
as a git `pre-push` hook, so obvious breakage is caught before a push
rather than after.

## Acceptance

- [ ] `pre-push` hook runs board lint/test and server unit tests (doctest,
      no PG container required) locally
- [ ] Hook is fast enough not to be routinely skipped (target: well under
      a minute)
- [ ] Documented in `docs/branching.md` or `CLAUDE.md` how to
      install/bypass it
