## Context

New task from `docs/HANDOFF.md` Section 4. Under D-18, generated output
ships as-is with no hand editing - rejection means regenerate with an
adjusted recipe. That only works if rejection is automatic, so this gate
**is** the quality mechanism, not a nice-to-have.

Per the handoff's suggested order (Section 7, point 6): **write this
before the generation chain** (T-0070-0074, T-0081-0083, T-0101) exists -
it turns generation into red -> green rather than a manual review step.

Image side (`13-asset-pipeline.md` Section 2, Section 4.8): palette
membership, index semantics (D-17/P-4 - index N means the same slot in
every asset), tile seamlessness, transition adjacency, cell fit, orphan
pixels, frame-silhouette delta.

Audio side (same sections): loop seam (on the *encoded* file, per T-0083 -
Ogg padding can break a seam clean in the source), LUFS, true peak, DC
offset.

## Acceptance

- [ ] Palette-membership check: every pixel maps to a valid home-palette
      index
- [ ] Index-semantics check: index `N` means the same palette slot across
      all assets (D-17)
- [ ] Tile seamlessness + transition-adjacency + cell-fit checks for
      tilesets
- [ ] Orphan-pixel and frame-silhouette-delta checks for sprites/animations
- [ ] Audio: loop-seam check runs against the encoded file, not the source
- [ ] Audio: LUFS, true-peak, and DC-offset checks
- [ ] All checks are automated and runnable pre-generation (red state) so
      the generation chain can be built against them (green state)
