## Context

`01-vision.md` §8 (Presentation, "Chroma = distance from home"): the home
universe is muted; anything that bled in renders in its own palette, and
the further it travelled, the more chromatically violent it is. Foreign
objects read at a glance, threat is legible before contact, and —
load-bearing — **time remaining is visible in the frame**: chroma
intensity is driven by collapse-clock proximity. The collapse clock is
never shown as a number; **the screen is the clock.**

`13-asset-pipeline.md` §3.0 (The load-bearing invariant): the chroma
mechanic renders foreign objects by swapping the palette LUT at runtime,
keyed on `origin_palette` (`04-data-model.md` §3 column). Assets are
indexed PNGs; the palette is a separate 1D LUT texture, not baked into
the image. Non-uniform index semantics across assets (P-4) would corrupt
the swap silently — this is the invariant the asset-validation gate
(T-0102) exists to protect.

**Because there is no HUD, this shader IS the core meta-timer mechanic,
not a cosmetic pass.** Cross-referenced as **A-4** ("Chroma-intensity
shader ramp vs. collapse proximity", `13-asset-pipeline.md` §7,
`05-art-direction.md`, `GDD-OPEN.md`) — Phase 6 asset-inventory item, but
the shader itself is client work, hence phase 5 here.

## Story

As the client, I want a LUT-substitution shader keyed on `origin_palette`
with a collapse-proximity intensity ramp, so that a player reads both
"this object is foreign" and "how close the universe is to collapse"
from the rendered frame alone, with zero UI cost.

## Acceptance

- [ ] Shader performs palette-LUT substitution on indexed sprites, keyed
      on each item/entity's `origin_palette` value — home-palette
      objects render unmodified, foreign-palette objects render through
      the substituted LUT
- [ ] A separate ramp parameter drives overall chroma intensity as a
      function of the identity's collapse-clock proximity
      (`collapse_expires_at`, `04-data-model.md` §1) — nowhere does this
      render as a number or numeric UI element
- [ ] Index semantics are uniform across assets feeding this shader
      (P-4) — the shader assumes index `N` means the same palette slot
      in every asset it touches; this task does not re-validate that
      (T-0102's job) but must not silently tolerate a mismatched asset
      producing garbage output
- [ ] Test: swapping `origin_palette` on a fixture sprite changes only
      its rendered colors, not its silhouette/index data
- [ ] Test: the intensity ramp is monotonic in collapse proximity across
      a representative range of `collapse_expires_at` values
- [ ] Visual regression fixture: same sprite at low vs. high collapse
      proximity produces visibly distinct output
