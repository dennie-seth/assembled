## Context

New task from `docs/HANDOFF.md` Section 4. Ratings now carry economic
weight (a well-rated note slows the author's bleed timer,
`docs/design/02-notes-system.md` Section 7), which makes sockpuppet
rating-farming a paying exploit. Defense: only a player whose run actually
contained the note's archetype may rate notes anchored there, checked
against `run_archetypes` (`docs/design/09-identity.md` Section 4).

## Acceptance

- [ ] `POST /v1/notes/{id}/rate` checks the caller's `run_archetypes` for
      a qualifying run before accepting the vote
- [ ] Test: rating a note anchored to an archetype absent from the
      caller's `run_archetypes` -> `403`
- [ ] Test: rating a note anchored to an archetype the caller did play ->
      succeeds normally
