## Context

`ClaudeCliRunner` (T-0020) produces a raw NDJSON stream on stdout. This
task parses that stream into typed events the rest of the runner (WS
relay, lifecycle state machine, run log) can consume without re-parsing
raw JSON everywhere.

**Bootstrap note:** implemented directly this session, ahead of the
runner's own existence.

## Acceptance

- [ ] Parser handles one event per line, tolerates partial lines buffered
      across reads
- [ ] Test: split UTF-8 sequences across chunk boundaries decode correctly
- [ ] Test: malformed JSON on a line is reported as an error event, not a
      crash
- [ ] Test: huge single lines don't blow a fixed buffer
