## Context

**Revised per `docs/HANDOFF.md` Section 3 (D-15).** Originally "game fully
playable with server down." Now precisely: **"fully *runnable* offline,
not completable."** Explore/survive/progress all work with no server
connection; only the ending (which requires simultaneous possession of
several uniques circulating through the network, INV-13) is unreachable
offline. This is still a hard requirement, not a nice-to-have - notes are
ambient flavour and a dead server must never block play.
