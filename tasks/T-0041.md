## Context

Local dev Postgres via `docker compose`, running on Rancher Desktop's
dockerd (moby) runtime per `docs/env-inventory.md` - not containerd, so
`docker compose` works verbatim. One Postgres per host on 5432 (mirrored
networking shares the host namespace).
