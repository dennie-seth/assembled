## Context

Cache godot-cpp build objects, Godot export templates, and server
dependency manager artifacts (vcpkg/conan) across CI runs so every push
doesn't rebuild the world.

## Acceptance

- [ ] Export templates cached (not re-downloaded every run)
- [ ] Server dependency cache (vcpkg or conan, whichever T-0040 picks)
      wired into ci-server.yml
- [ ] Measurable CI time reduction on a cache-hit run vs. cold
