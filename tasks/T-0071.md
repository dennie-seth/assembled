## Context

The agent that drives ComfyUI: takes a workflow JSON template, submits it
via `POST /prompt`, polls `/history` for completion, and fetches the
result via `/view`. Base class shared with the audio pipeline's
`AudioAgent` (T-0082) - DRY per `docs/PLAN.md` Phase 7.

Asset strategy is **archetype-first** (`docs/design/05-art-direction.md`
Section 4): each archetype (Hospital, Signal Tower, etc.) gets a coherent
asset set generated as one `art/*` branch, merged whole per the binary
asset policy (`docs/PLAN.md` Section 2). Variants reuse an archetype's
tileset with different props/decay/palette weighting rather than
regenerating from scratch - keep the workflow templates parameterized so
a "dress this archetype differently" run doesn't require a new template.
