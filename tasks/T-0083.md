## Context

Normalize generated audio to EBU R128 loudness and set up Godot import
presets so audio assets land consistently mixed.

**Revised per `docs/HANDOFF.md` Section 3 (`13-asset-pipeline.md`
Section 4.7).** Add the **loop-fold step** and a **seam assertion**.
Critically, validate the seam on the *encoded* file, not the source -
Ogg Vorbis padding can introduce a seam that was clean before encoding,
so a check that only runs pre-encode would pass files that click or pop
in-engine.
