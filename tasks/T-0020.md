## Context

Foundational interface for the Agent Runner (Phase 2 goal: card -> agent
execution -> streamed result -> card moves). `AgentRunner` is the
abstraction; `ClaudeCliRunner` is the concrete implementation that spawns
`claude -p --bare --output-format stream-json` as a child process per card
run. Everything else in Phase 2 (stream parsing, WS wiring, lifecycle,
kill/cancel, run logs, tool allowlisting) builds on this.

**Bootstrap note:** this task (and the rest of T-0020..T-0027) is being
implemented directly in this session rather than run through the Agent
Runner itself - the runner doesn't exist yet, so it can't build itself.
