## Context

Vendor libcurl and drive its multi-handle interface from Godot's
`_process` callback so HTTP calls to the server never block the main
thread. Foundation for `NoteClient` (T-0063).

## Acceptance

- [ ] libcurl vendored into the build (not a system dependency assumption)
- [ ] Multi-handle pumped from `_process`, non-blocking
- [ ] Test: verifies no main-thread block occurs during an in-flight
      request (e.g. frame timing stays consistent while a request is
      pending)
