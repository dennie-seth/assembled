## Context

HANDOFF §22.1 (raised 2026-08-22). Two character-asset artifact classes make CONTRADICTORY provenance claims, and this must be resolved before committing to four character-LoRA training runs:

- `entities_concept_sheet_v1.png` (1.37MB, produced via T-0210) claims real ComfyUI generation — carries `prompt_id` + `workflow_hash`.
- The T-0200 sheets (`watcher_idle_sheet_v1.png` and siblings, ~950 bytes) claim procedural generation — invoked via `synth_entities.py` through `tests/conftest.py`, marked "not AI-generated".

Related but distinct: T-0215 is (as of this writing) in `validation`, fixing `model_hash: null` enforcement across this same asset family. That is a missing-field defect. This card asks a different question: are the *non-null* provenance claims these two artifact classes already make actually TRUE? T-0215 does not check that.

Also directly relevant as supporting evidence: T-0212 (player idle-sheet generation spike, currently `done`) had a reviewer PASS overturned by a human comment (2026-08-21) — the committed "real SDXL img2img" deliverable was actually a re-rendering of the T-0209 concept sheet's multi-pose layout, not idle-animation frames of one character. The automated checks that passed it twice (pixel-hash-vs-placeholder, provenance-field-presence) never verified actual frame content; only a human eyeballing the image caught it. That incident is a live example of exactly the failure mode this card investigates: a provenance/gate record can read PASS while being wrong.

## Story

As the asset pipeline, I need to know — with evidence, not assumption — whether T-0200's procedural-generation claim and T-0210's real-generation claim are both true, before spending the cost of four character-LoRA training runs whose justification depends on the character pipeline's provenance records being trustworthy.

## Acceptance

The discriminator is REPRODUCIBILITY, not novelty. Run all four checks and record evidence for each:

1. Re-run `synth_entities.py` with the recorded params for the T-0200 sheets. Byte-identical PNGs ⇒ provenance correct (procedural). Different or absent ⇒ provenance wrong.
2. Check ComfyUI `/history` for a `prompt_id` matching the T-0200 sheets. A hit proves real generation occurred, contradicting the procedural claim.
3. Check git history for when/what commit the T-0200 PNGs entered the tree — a test-fixture write and an agent-committed generated-output leave different trails.
4. Inspect pixels: procedural = perfectly straight edges + exactly the declared index set. A descended SDXL output = quantization irregularity.
