## Context

**Revised per `docs/HANDOFF.md` Section 3 (D-19).** Originally an
authoring-time tool; **moves to a CI build step.** Per-archetype atlases
would otherwise be written by two different `art/*` branches, violating
the strictly-additive rule - commit individual sprites, pack them
deterministically in CI instead. Atlases are build artifacts, not
committed.

This adds a **determinism requirement**: the same set of input sprites
must produce a byte-identical packed layout, every time, on every runner.

**A-1 is now resolved (D-16):** tiles are **16px**, rooms authored on a
24x14 grid (384x224) with an 8px non-gameplay band. The packer's
tile-grid constant should be set to 16, not left open.

Also assert the packed atlas is still **PIL mode `P`** (indexed) after
packing - Pillow silently converts to RGB on some operations, which would
corrupt the index-semantics contract from D-17/T-0073 without raising an
error.

## Acceptance

- [ ] Packing runs as a CI build step (rectpack + Pillow), not an
      authoring-time tool; packed atlases are gitignored, not committed
- [ ] Test: same input sprite set -> byte-identical packed `.tres` atlas
      layout, run twice
- [ ] Atlas loads correctly in the Godot editor/client
- [ ] Tile-grid constant is set to 16px per D-16, still a single
      configurable value rather than hardcoded inline in multiple places
- [ ] Test: packed atlas is asserted to still be PIL mode `P` after
      packing; a silent RGB conversion fails the build
