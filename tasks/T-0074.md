## Context

Packs post-processed sprites (rectpack + Pillow) into a Godot `.tres`
atlas, ready for the client to consume.

**Tile size is still open (A-1, `docs/design/05-art-direction.md`
Section 5):** 16px gives 24×13.5 tiles per 384×216 screen (a half-tile
band - awkward); 24px gives a clean 16×9. Worth deciding with the first
real tileset (T-0072/T-0073 output) rather than in the abstract, but the
packer's tile-grid assumption should be a single configurable constant,
not hardcoded, since this decision may land after this task starts.

## Acceptance

- [ ] Packer produces a valid Godot `.tres` atlas from a set of
      post-processed sprites
- [ ] Atlas loads correctly in the Godot editor/client
- [ ] Tile size is a single configurable value, not hardcoded inline,
      given A-1 is still open
