## Context

The vertical slice's three hazard entities, each wired to exactly one
sensor from the kit (`11-moment-to-moment.md` §1). Naming reuses existing
HAZARD vocabulary from the notes system (`02-notes-system.md` §2) -- no
new localization cost.

## Acceptance

- [ ] The Watcher carries the sight-cone sensor only (depends on Sensor
      kit); reads as stationary or slow-patrol, telegraphed and avoidable
      by routing
- [ ] The Sound carries the sound-radius sensor only; roams and converges
      on noise, punishing running blind
- [ ] The Still Air carries the proximity/patrol sensor only, no LOS
      check; reads as inevitable rather than alert
- [ ] None of the three entities combines sensors -- combining is
      explicitly deferred past the slice (11 §1)
- [ ] Entity names/labels reuse existing HAZARD vocabulary (02 §2) rather
      than introducing new localized strings
- [ ] Test: each entity's detection behavior is driven entirely by its
      single attached sensor from the Sensor kit, with no entity-specific
      detection logic duplicated outside the sensor kit
- [ ] Edge case: an entity catching the player while the player is
      mid-transition into a hiding spot still counts as a catch, per the
      Hiding card's no-i-frame rule
