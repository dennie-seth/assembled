Root of Phase 6. Install ComfyUI on the dev box, running with `--listen`
so the AssetAgent (T-0071) can drive it over HTTP. Document the GPU/VRAM
baseline this dev machine provides, since it constrains model choice for
the rest of the pipeline (8GB VRAM per `docs/design/GDD-QUESTIONS.md`

`docs/design/05-art-direction.md`: pixel art, **384×216** internal

camera, locked palette, Soviet constructivist/brutalist direction. Model
selection in this task should favor whatever SDXL/pixel-art LoRA stack
best supports that target - the resolution and style are fixed inputs,
not things this task decides.
