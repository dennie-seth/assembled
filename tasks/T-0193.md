## Context

HANDOFF §20-a2. Follows the T-0192 side-on one-room blockout rebuild (§20-a1).
The T-0192 blockout established the physical geometry and sensor constants for
the Power Substation room in side-on view. This card measures that blockout
across six concrete dimensions so that the `14` §10 M-2 design table values
can be grounded in observed data rather than top-down estimates.

Grounded in `docs/design/14-vertical-slice.md` §10 (sensor/patrol parameters)
and `docs/decision-log.md` (decision-log protocol).

## Story

As the game designer, I want six measured values from the committed blockout —
cross-room traversal time, time under Watcher observation, warning tile count,
unavoidable-detection verdict, cover-vs-hiding read, and room-vs-corridor read
— recorded as a decision-log entry, so that `14` §10's M-2 parameter table is
grounded in observed prototype data and any top-down estimates from before the
blockout existed are explicitly voided.
