## Context

New task from `docs/HANDOFF.md` Section 4. Implements `session_lease`
(`docs/design/04-data-model.md` Section 1) and the identity/session model
from `docs/design/09-identity.md` Section 3: a lease, not a boolean flag,
so a crashed client isn't locked out - it just waits out a short TTL. A
new session for the same identity evicts the old one; the evicted client
is told its universe continued elsewhere.

## Acceptance

- [ ] Acquiring a session issues a fresh `lease_id` + short TTL, evicting
      any existing live lease for that identity
- [ ] Test: lease expiry makes the session reclaimable
- [ ] Test: takeover evicts the prior session (its next heartbeat fails)
- [ ] Test: crash recovery - a client that stops heartbeating is not
      permanently locked out once the TTL elapses
