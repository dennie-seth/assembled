As a user I want to be able to see newest or oldest tasks on the top of the list, so I can manage them easier.

## Context

The board's per-column sort dropdown (added in T-0032/board-deps-blocker-sort) supports sort keys defined in `SORT_KEYS` and `SORT_COMPARATORS` in `tools/board/src/client/board.js`. At the time of that feature, only `id`, `priority`, `agent`, and `phase` were available. Users managing a large backlog need to find recently created or oldest unresolved tasks quickly; a date-based sort on the `created` frontmatter field covers this directly. The labels surface in the column sort dropdown via `SORT_LABELS` in `boardView.js`.

## Acceptance

- [ ] `SORT_KEYS` in `tools/board/src/client/board.js` includes both `"oldest"` and `"newest"`.
- [ ] `SORT_COMPARATORS` contains an `oldest` entry that sorts tasks by `created` ascending (lexicographic on ISO date string), falling back to id order on equal dates.
- [ ] `SORT_COMPARATORS` contains a `newest` entry that sorts tasks by `created` descending, falling back to id order on equal dates.
- [ ] `SORT_LABELS` in `tools/board/src/client/boardView.js` maps `"oldest"` → `"Oldest"` and `"newest"` → `"Newest"`, making them appear in the sort dropdown.
- [ ] Vitest tests for the `oldest` and `newest` comparators exist and are green (tasks with different `created` values sort correctly; ties break by id).
